# Prototype Zero v0.3

Playtest focus: restore the basic playable loop.

- Direct board movement: no Move mode/button.
- Hover empty tiles to preview path and AP cost; click to move.
- Hover enemies to see in-range/out-of-range reason, hit chance, range, and AP cost.
- Click a legal enemy target to open attack confirmation.
- Click any unit to inspect its combat summary.
- Initiative detail rows omit the redundant repeated d10 label.

Combat math remains provisional; this build is primarily an interaction/usability test.

# Prototype Zero — Playable v0.1

## Run it
1. Unzip the package.
2. Double-click `index.html`.
3. It opens in your normal web browser. No installation or server is required.

## Included in v0.1
- 15 × 15 flat tactical grid
- Four heroes: Knight, Archer, Wizard, Cleric
- Six generic test enemies
- 3 AP per turn
- Up to 4 tiles of movement per 1 AP
- Individual initiative using d10 + Intelligence, rerolled each round
- Physical attacks versus AC and magical attacks versus MR
- HP, damage, critical hits, automated enemy turns
- Current test loadouts represented in the combat values

## Intentionally not implemented yet
- Cover and elevation
- Opportunity attacks / reactions and Disengage
- Full spell and class ability kits
- Equipment UI / character creation
- Art, animation, audio, campaign progression
- Save/load

This is a vertical-slice mechanics build intended to make the first battle playable and expose balance/design problems.

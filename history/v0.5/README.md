# Prototype Zero v0.5

Focus: pathing, persistent tactical feedback, compact initiative, character-sheet refinement, and one-screen UI work.

## Changes
- Movement path selection was revised toward more direct, human-readable routes.
- Invalid movement and attack attempts were logged and given persistent explanations.
- Initiative was collapsed into a compact expandable control.
- The standalone Attack Info button was removed in favour of character-sheet and battlefield information.
- The expanded character sheet gained fuller attributes, equipment, and attack information.
- Back to Battlefield behaviour was strengthened.

## Historical note
This build experimented with chronological combat-log ordering (oldest first). That decision was later reversed; v0.6 uses newest-first ordering.

The complete original v0.5 browser build is preserved in the packaged ZIP under `releases/`.

# Historical Browser Builds

This folder preserves source snapshots and notes for the Prototype Zero browser prototype.

- v0.1 through v0.4 have direct HTML source snapshots.
- v0.5 is preserved in its complete original packaged ZIP under `../releases/`; the standalone HTML file was not separately retained in Google Drive.
- v0.6 onward have direct HTML source snapshots and version notes.
- The current playable build is also mirrored at the repository root as `index.html`.

GitHub version control was introduced after the earliest browser builds already existed, so the historical import commit timestamps for those versions reflect the later repository migration rather than the original build dates.

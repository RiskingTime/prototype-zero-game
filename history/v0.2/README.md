# Prototype Zero — Playable v0.2

Open `index.html` in a desktop browser. No installation or server is required.

## v0.2 playtest changes
- Combat UI designed to fit in one 16:9 viewport without page scrolling.
- Expandable initiative audit log with d10, INT bonus, total, and order.
- Movement mode highlights legal destinations and previews the path before committing.
- Attack mode highlights valid targets, shows hit chance/AP cost, and requires confirmation.
- Battlefield feedback appears for hit, miss, critical, movement, and AP spend.
- Columns A–O and rows 1–15 provide playtest coordinates.
- Contextual guidance tells the player what to click next.

## Still intentionally provisional
Attack bonuses remain the same placeholders as v0.1 until the earlier combat modifier ladder is reconciled with the design document. Reactions/opportunity attacks, Disengage, cover/elevation, full class abilities, and nuanced weapon penetration are not yet implemented.
